# Dashboard and Cats list

## Dashboard

The Dashboard is the first page in the sidebar. Admins and Volunteers can open it. It shows a summary of the work in Oriel.

### Number tiles

The page has six tiles. Each tile shows a count. Click the number to open a list of the items behind it. A row in the list opens the cat or the application when your role may open that page.

- "Awaiting Passport" counts cats whose status is Awaiting Passport.
- "Pending Matching" counts applications that are in a matching stage and are not matched to a cat yet. It is the same list as the "Needs Match" tab on the Matching page.
- "Escalations Required" counts post-adoption cases marked as urgent.
- "Tasks Due Today" counts tasks due today that are not Completed or Cancelled.
- "Travel Pending" counts travel records that are not Completed or Cancelled.
- "My Open Cases" counts the applications that you own and that are in an open stage. A line under the number shows how many are in each stage.

### Panels

- "Recent Activity" lists the five latest changes. Click an entry to open the item it belongs to, when a link exists. Admins also see a "View all" link to the Activity Log.
- "Upcoming Tasks" lists up to five open tasks that have a due date, soonest first. An overdue task has an "Overdue" label. Tasks due after the planned number of days appear under a "Later" heading. Admins also see the owner of each task. "View all" opens the Tasks page.
- "Quick Actions" has three buttons: "Add Cat", "Create Active Application" and "Create Task". Each opens a form.

Admins also see an "Invite to Add Cat" button at the top of the page. It asks for the full name and email address of a foster or a rescuer and sends that person a single-use link to the Add Cat form. The link works for 3 days. If the email service is not set up, Oriel creates the invitation but does not send the email, and it says so.

## Cats list

The "Cats" item in the sidebar opens the Cats list. Admins and Volunteers can open it. The page shows one card for each cat.

### What a card shows

A card shows the cat's name, gender, age in years, country, status, the rescuer and the date the cat was created. Click a card to open the cat page.

### Status tabs

The tabs at the top filter the list by status. The first tab is "All". The other tabs are Awaiting Profile, Intake, Awaiting Passport, Awaiting Media, Adoption Ready, Reserved, Adopted, Fostered and Archived. Each tab shows the number of cats in it.

### Searching

The "Search cats" box filters the list as you type. It looks at all the details of a cat, such as the name, breed, colour and rescuer. Admins can also search by microchip number. For Volunteers the search does not match the microchip number. The counts on the tabs follow the search. The search text stays in the page address, so a reload keeps it.

### Buttons

- "Add Cat" opens the form to add a cat. Admins and Volunteers can use it.
- "Create Shareable Link" is visible to Admins only. It asks whether the link is for "A foster (the form asks which foster)" or "A rescuer". Then "Create Link" makes a link that works for one cat only. Oriel shows the expiry date and a "Copy Link" button. Send the link to the person who will fill in the form.

## Adding a cat

Open the form with "Add Cat" on the Cats list or on the Dashboard. The only required field is "Name". Everything else can be filled in later on the cat page. The form has these sections.

- Core Identity: "Name", "Gender", "Age", "Breed" and "Colour". You can pick a breed or colour from the list or type your own.
- Rescuer / Foster: "Linked Rescuer", "Foster Contact" and "Foster Location".
- Personality & Behaviour: "Personality Summary", "Energy Level", "Lap Cat", "Indoor Only", "Child Friendly", "Cat Friendly", "Dog Friendly" and "Special Notes".
- Medical: "Medical Summary", "Vaccinated", "Neutered", "FeLV Status", "FIV Status", "Medication Required" and "Microchip Number".
- Media & Documents: "Upload Photos", "Upload Videos", "Upload Medical Documents" and "Upload Passport File".

A file can be at most 20 MB. Photos must be image files and videos must be video files.

Any staff member can type a microchip number when adding a cat. Only Admins can see it afterwards (see "Who can see what" in the cat page guide).

### Adding bonded cats together

Click "Add Another Cat" in the form to add a second cat in the same form. Each cat has its own tab and its own details. When you save, the cats are linked as "Bonded With". The save button then reads "Add 2 Cats" (or the right number). A bonded group can have only a limited number of cats, which is set in App Settings. A message appears when the limit is reached. The "X" on a cat's tab removes that cat from the form.

### After saving

If a file fails to upload, the cat is still added. Oriel shows a warning that lists the failed files. Add them later on the cat's "Documents" tab.

When a cat is added, Oriel also asks the AI to write a draft advert for it. See the "Advert" tab in the cat page guide.

A foster or a rescuer can also add a cat through a link that an Admin sends. See "Create Shareable Link" above.
