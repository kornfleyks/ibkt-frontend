# Matching

The "Matching" item in the sidebar opens the Matching page. Admins and Volunteers can open it. The page links an adoption application to an Adoption Ready cat, or to a bonded group of cats.

## What the page shows

The page shows application cards, not cats. An application appears only when its stage is one of the matching stages. The stages are named in the page subtitle. An Admin sets them in App Settings.

A card shows the applicant's name, city and country, the application stage, the priority and the Case Owner. A matched application also shows the cat names and the match confidence.

Admins see all applications. A Volunteer sees only the applications that the Volunteer owns. Admins have a "My cases" switch at the top of the page to show only their own applications.

## Tabs and search

- "Needs Match" lists applications that have no cat yet.
- "Matched" lists applications that have a cat.

Each tab shows its number of applications. The "Search applications" box filters by name, email, phone, cat and other details.

## Matching an application to a cat

1. Open the "Needs Match" tab and click an application card.
2. Read the application summary on the left. It shows household, existing pets, work schedule, cat experience and AI concerns when the application has them. "Open application" opens the full application in a new browser tab.
3. Pick a cat on the right. Use "Search cats" to find a cat by name. Each option shows the gender, age, breed, energy level, and whether the cat is good with children, cats and dogs and whether it is indoor only. A "Needs medication" label shows when the cat needs medication. The personality summary is shown too.
4. Choose a "Match Confidence": High, Medium or Low. It is required.
5. Click "Match with" followed by the cat names.

A bonded group is shown as one option with the label "Bonded group of 2 - matched together" (or the right number). You cannot pick one cat of a group. The whole group is matched together.

When the match is saved, the cats are linked to the application and their status changes to Reserved. The match confidence is saved on the application. A message at the top of the page confirms the match. If some changes did not save, the message lists them.

## Which cats are offered

A cat is offered only when its status is Adoption Ready and it is not linked to an adopter. Every cat in a bonded group must meet this rule. If no cat qualifies, the dialog says that no cats are available to match.

A cat can be set to Adoption Ready only when its details are complete. This means an incomplete cat cannot be matched by mistake. See "Changing a cat's status" in the cat page guide.

If another person changed the data while the dialog was open, Oriel shows a message and asks you to close the dialog to refresh the list.

## Removing a match

1. Open the "Matched" tab and click the application card.
2. Read the message "Remove this match?". It says that the application will be unlinked from the cats, that the cats go back to Adoption Ready and that the Match Confidence is cleared.
3. Click "Unmatch" to confirm, or "Cancel".
