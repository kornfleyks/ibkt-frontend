# Active Applications and Add Application

## What the Active Applications page is for

The "Active Applications" page lists the people who have applied to adopt a cat. Open it from "Active Applications" in the sidebar. Admins and Volunteers can see the page.

An Admin sees every application. A Volunteer sees only the applications where that Volunteer is the Case Owner. An Admin can turn on the "My cases" switch at the top of the page to see only their own applications.

## The three tabs

The page has three tabs. Each tab shows how many applications it holds.

- "New Applications" holds applications in the stage New Application.
- "Active" holds applications in the stage Active Application.
- "Rejected" holds applications in the stage Rejected Application.

Applications in other stages (Approved, Completed or Archived) are not listed on this page. Approved applications are listed on the "Adoptions" page.

## The application cards

Each application is one card. A card shows the applicant name, the city and country, and the stage. It also shows the priority when one is set, the Case Owner, the date the application was created, and the linked cat. A card with no linked cat says "No cat linked".

Click a card to open the application page. The tabs of that page are described in the guide section about the application page.

## Searching

Type in the "Search applications" box to filter the cards of the current tab. The search looks at the name, email, phone, cat, owner and the answers on the application. The search text stays in the address of the page, so a reload keeps it.

## Adding an application

Click "Add Application" at the top right of the page to enter an application yourself. This is the staff copy of the Pre-Adoption Form that applicants fill in. It saves the application in Oriel only.

The form has five steps, shown at the top of the window.

1. "Your interest": how the person heard about us, a friend or relative name when that is the answer, and which cats they are interested in.
2. "Your details": full name, email, home address, how long they have lived there, and phone number.
3. "Your home": the type of home, garden access, activity level, who lives in the home, and whether the family agrees.
4. "Experience and lifestyle": pet experience, reasons for adopting, current pets, hours the pet is left alone, allergies, who cares for the pet, and whether a pet has ever gone missing.
5. "Preferences": age and cat preferences, the 15 to 20 year commitment, outdoor access, a typical day, optional photos and a contact consent question.

Click "Next" to move on. Oriel checks the required questions of the step before it lets you continue. Click "Back" to return to an earlier step. Required questions that are missing are listed above the buttons in a red message.

On the last step, click "Add Application" to save. Photos must be an allowed file type and no larger than 10 MB each. If some photos fail to upload, the application is still created and a warning lists the files that failed.

## What happens after saving

- The new application is created in the stage New Application, and the "New Applications" tab is shown.
- The person who entered the application becomes its Case Owner.
- Oriel does not allow a second open application for the same email address. If one exists, a red message appears with an "Open it" link to the existing application. An application counts as open until it is Rejected, Archived or Completed.
- The answers are saved with the application. Use the "Preview" button on the application page to read them later.

## Applications that arrive from the public form

An applicant can also fill in the Pre-Adoption Form themselves from a public link (see the guide section about forms). That creates a new application in the stage New Application. Staff then see it on the "New Applications" tab.
