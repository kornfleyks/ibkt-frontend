# Tasks

## What the Tasks page is for

The "Tasks" page lists work for the team. A task can be linked to a cat, to an application, or to both. Open the page from "Tasks" in the sidebar. Admins and Volunteers can see it.

An Admin sees all tasks. A Volunteer sees only the tasks where that Volunteer is the Owner. An Admin can turn on the "My tasks" switch to see only their own tasks.

## Tabs and search

The page has four tabs. Each tab shows how many tasks it holds.

- "Open" shows tasks with the status New, In Progress or Waiting.
- "Completed" shows completed tasks.
- "Cancelled" shows cancelled tasks.
- "All" shows every task.

Tasks are sorted by due date, with the earliest first. Tasks without a due date come last. Use the box "Search by task, cat, application or owner" to filter the list.

## A task card

Each task is a card. A card shows the title and chips for the priority and the status. It also shows the linked cat and the linked application as chips, the description, the owner, the due date, the waiting reason when the status is Waiting, and the created date. Click a cat chip or an application chip to open that cat or application.

An open task whose due date has passed shows a red "Overdue" chip and a red due date.

Tick the checkbox on the left of a card to mark the task Completed. Untick it to set the task back to New.

Move the pointer over a card to see two icons. The eye icon ("View task") opens the full task read-only. The pencil icon ("Edit task") opens the full task for editing. When editing, use the save icon ("Save task") to keep the changes or the cancel icon to leave them.

## Adding a task

Click "Add Task" at the top right of the page. A window opens with these fields. Every field is required.

- "Cat" and "Application": choose at least one. A message "Pick a cat or an application." appears when both are empty. The application list contains the applications you are allowed to open.
- "Title": type a title, or pick one of the titles offered.
- "Description".
- "Status": New, In Progress, Waiting, Completed or Cancelled.
- "Priority": Low, Medium, High or Urgent.
- "Waiting Reason": appears only when the status is Waiting.
- "Due Date".
- "Owner": the person who is responsible for the task.

Click "Add Task" in the window to save, or "Cancel" to leave. A message under the fields tells you which required field is missing.

## Tasks on a cat or an application

The "Tasks" tab of an application page lists only the tasks linked to that application. Its "Add Task" button creates a task already linked to the application, so the window does not ask for a cat or an application. On the application tab, everyone who can open the application sees all its tasks. Admins also get the "My tasks" switch there.

The cat page has a "Tasks" tab that works the same way for a cat. There, a Volunteer sees only the tasks assigned to them.

When a task is linked to a cat or application, the cat or application name appears as a chip on the card on the "Tasks" page, and the chip opens that record.
