Design written 2026-10-16 in `docs/rescuer-onboarding.md`; nothing built. Decisions the user made (don't re-ask): rescuer login lives on the Users board with Role = Rescuer (separate login URL and portal layout); onboarding form is a public in-app page saved to an app-only table `rescuer_applications`; only Admin and Super Admin review; a cat a rescuer adds is a normal Cats record with status Intake linked to the rescuer, not listed until staff review, and read-only for the rescuer afterwards.
